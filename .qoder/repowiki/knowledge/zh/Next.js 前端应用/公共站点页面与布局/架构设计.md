- 入口与边界：`web/app/layout.tsx` 定义根布局并注入 `ThemeProvider` 与客户端 `LayoutWrapper`；`web/app/LayoutWrapper.tsx` 基于路径判断是否为 `/admin`，非管理端时渲染 `Header`/`Footer` 与主内容区。
- 页面分层：静态/服务端渲染页面（`page.tsx`、`about/page.tsx`、`labels/page.tsx`、`labels/[tag]/page.tsx`）直接调用 `@/lib/api` 获取数据；交互型页面（`search/page.tsx`、`auth/login/page.tsx`）采用客户端组件 + `Suspense` 包裹表单逻辑。
- 依赖方向：页面层仅依赖共享 API 客户端与类型（`@/lib/api`、`@/lib/types`）及通用 UI 组件（`ArticleCard`、`Pagination`），不反向依赖管理端模块。
