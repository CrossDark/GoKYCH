- **路由隔离**：利用 `app/admin` 目录结构划分管理后台，`LayoutWrapper` 根据路径前缀动态决定是否渲染公共导航（Header/Footer），实现公共区与管理区的布局解耦。
- **统一 API 代理**：通过 `next.config.ts` 将 `/api/*` 请求反向代理至 Go 后端（localhost:8000），前端所有模块共享此通信契约。
- **共享数据层**：`lib/api.ts` 封装了统一的 `request` 函数，自动处理 CSRF Token 注入、服务端 Cookie 转发及错误标准化，为所有页面组件提供一致的后端交互能力。
- **全局状态与主题**：根布局 `layout.tsx` 集成 `ThemeProvider` 和防闪烁脚本，确保全站主题切换的一致性。
