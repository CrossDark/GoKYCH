- **布局与路由**：采用 Next.js App Router 结构，以 `layout.tsx` 为根容器，通过 `page.tsx` 实现各子模块（如 `/admin/articles`, `/admin/users`）的页面渲染。
- **权限控制**：在 `layout.tsx` 中集成客户端鉴权逻辑，通过 `getMe` 校验用户角色（admin/owner），未授权时自动重定向至登录页。
- **交互模式**：全模块采用 "use client" 指令，依赖 React Hooks (`useState`, `useEffect`) 管理本地状态，并通过 `@/lib/api` 封装层与后端进行异步数据交互。
- **组件复用**：各业务页面共享统一的 UI 风格与交互范式，如使用 `<details>` 标签折叠表单、统一的 `.admin-table` 表格样式及消息提示机制。
