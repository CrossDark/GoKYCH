## TypeScript 类型检查错误

### 错误 1: webkitdirectory 属性不存在

**文件**: `app/admin/themes/page.tsx`（第 223 行）

**错误信息**:
```
error TS2322: Type '{ ref: RefObject<HTMLInputElement | null>; type: "file"; accept: string; style: { display: "none"; }; onChange: (e: ChangeEvent<HTMLInputElement, Element>) => void; disabled: boolean; webkitdirectory: string; }' is not assignable to type 'DetailedHTMLProps<InputHTMLAttributes<HTMLInputElement>, HTMLInputElement>'.
Property 'webkitdirectory' does not exist on type 'DetailedHTMLProps<InputHTMLAttributes<HTMLInputElement>, HTMLInputElement>'.
```

**原因分析**:
`webkitdirectory` 是一个非标准属性（WebKit 前缀），TypeScript 的标准类型定义中不包含此属性。

**修复方案**:
使用 `@ts-ignore` 注释或类型断言来绕过类型检查：
```tsx
<input
  ref={uploadRef}
  type="file"
  accept=".zip,.css"
  style={{ display: "none" }}
  onChange={handleUploadSelect}
  disabled={uploading}
  // @ts-ignore - webkitdirectory is a non-standard WebKit property for folder uploads
  webkitdirectory="true"
/>
```

## ESLint 错误分类

### 1. React Hooks 相关错误

#### 1.1 在 useEffect 中直接调用 setState

**涉及文件**:
- `components/admin/RevisionDrawer.tsx`（第 89 行）
- `components/admin/RevisionRestoreModal.tsx`（第 77 行）
- `components/admin/ThemeSettingsModal.tsx`（第 113 行）
- `components/admin/UserAvatar.tsx`（第 48 行）

**错误信息**:
```
Error: Calling setState synchronously within an effect can trigger cascading renders
```

**原因分析**:
在 useEffect 的同步代码中直接调用 setState，可能导致级联渲染影响性能。

**修复建议**:
- 将 setState 移到异步回调中
- 使用 useLayoutEffect 替代 useEffect（如果需要同步更新）
- 重新评估是否真的需要在 effect 中更新状态

#### 1.2 useEffect 缺少依赖

**涉及文件**:
- `components/admin/ThemeSettingsModal.tsx`（第 113 行）
- `lib/admin-feedback.tsx`（第 53 行）

**错误信息**:
```
React Hook useEffect has a missing dependency: 'load'. Either include it or remove the dependency array
```

**修复建议**:
- 将缺失的依赖添加到依赖数组中
- 如果依赖会频繁变化，使用 useCallback 包裹

## 错误来源分析

### CSS 文件中的大量错误

ESLint 报告的 39494 个错误中，绝大多数来自主题 CSS 文件（如 `data/themes/glass/static/theme.css`）。这是因为：

1. **CSS 文件被作为 JavaScript 解析** - ESLint 配置可能没有正确识别 CSS 文件类型
2. **CSS 规则重复** - 主题 CSS 中可能包含大量重复的规则或选择器

**建议**:
- 在 `.eslintignore` 中添加主题 CSS 文件路径
- 或配置 ESLint 使用 `eslint-plugin-css` 等插件来正确处理 CSS 文件
