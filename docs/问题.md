## 已修复问题

### 🔴 Bug #1：搜索功能崩溃

**严重程度**：高

**现象**：访问 `/search` 页面搜索任何关键词，页面崩溃报错：
```
Runtime TypeError: Cannot read properties of undefined (reading 'length')
at components/ArticleCard.tsx (12:25)
```

**根因**：
1. 后端 `SearchArticles` 函数（`internal/content/articles.go`）查询文章后**未批量获取标签**，导致返回的文章对象缺少 `tags` 字段
2. 前端 `ArticleCard.tsx` 直接访问 `article.tags.length`，未做空值防御

**修复**：
- **后端**：在 `SearchArticles` 函数中添加 `GetTagsForArticlesBatch` 调用（与 `ListArticles` 保持一致）
- **前端**：`ArticleCard.tsx` 改用 `article.tags?.length ?? 0` 可选链防御

**验证**：搜索 "Hello" 返回 3 条结果，空搜索显示友好提示，控制台无错误。

## 待处理项

### 🟡 配置 #1：导航栏缺少子站点链接

**严重程度**：中（配置问题，非代码 Bug）

**现象**：顶部导航栏中间的子站点链接（MD、Wikidot、HTML、BBCode、Typst）未显示。

**原因**：数据库 `subsite_links` 表为空。Header 组件从 `/api/home` 获取 `subsite_links`，返回空数组。

**建议**：通过管理后台 `/admin/home` 页面添加子站点链接：
- MD → `/md`
- Wikidot → `/wikidot`
- HTML → `/html`
- BBCode → `/bbcode`
- Typst → `/typst`
