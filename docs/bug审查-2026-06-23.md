### 2. HTTP Server 无超时
**位置**: `cmd/gokych/main.go:85-88`

```go

```

**修复**: `ReadTimeout=10s, WriteTimeout=30s, IdleTimeout=120s`。

**工时**:5min

### 3. X-Request-ID 接受客户端任意值
**位置**: `internal/api/requestid.go:20-23`

不校验客户端 `X-Request-ID` 格式,含换行符可污染 slog 输出。

**修复**:用正则校验(如 `^[a-zA-Z0-9-]{8,128}$`),不合法的用 `uuid.NewString()` 覆盖。

**工时**:10min

### 4. 内容字段无长度上限
**位置**:
- `internal/content/comments.go:82` `AddComment` 的 `content`
- `internal/api/admin.go:176-222` 通知 title/content
- `internal/api/admin.go:339` `addSubsiteLink` 的 description

**工时**:30min

### 5. `getArticle` 聚合层错误被吞
**位置**: `internal/api/articles.go:92-118`

comments/lineComments/lineCounts/rating 任意失败只 `slog.Error` 后继续返回 200 + null,前端崩。

**修复**:任一子查询失败 → 返回 500 + 明确错误。

**工时**:15min

### 6. `getArticle` ETag 304 路径查询浪费
**位置**: `internal/api/articles.go:78-118`

ETag 校验前已经跑了所有子查询,304 时白做。

**修复**:先算 ETag,304 直接 short-circuit,没命中再走子查询。

**工时**:15min

### 7. Admin handler 错误被吞
**位置**:

**修复**:显式检查 `err`,失败返 500 + slog。`getAdminHome` 的两个查询也要记错误日志。

**工时**:30min

### 8. Subsite link URL 可注入 `javascript:`
**位置**: `web/components/Header.tsx:67` `href={link.url}`

React 16+ 不再过滤 `javascript:` 协议。后端 `addSubsiteLink` 无 scheme 白名单。

**修复**:后端 `addSubsiteLink` 加 scheme 白名单(`http`/`https`/`mailto` 之外一律 400);前端给 `<a>` 加 `rel="noopener noreferrer"`。
