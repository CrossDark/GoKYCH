## 2. 主题颜色解析错误

### 错误信息
```
[getThemeColors] TypeError: Cannot destructure property 'exportedColors' of 'undefined' as it is undefined.
at :433:12185
```

### 原因分析
某个函数尝试解构 `exportedColors` 属性，但源对象为 `undefined`。错误发生在浏览器端的匿名脚本中（`:433:12185`），可能是外部脚本或内联脚本。

### 影响范围
- 主题颜色提取功能可能失效
- 可能影响主题切换时的颜色同步

### 处理建议
1. 搜索代码库中 `exportedColors` 或 `getThemeColors` 相关代码
2. 添加空值检查和错误处理
3. 确保主题配置完整时再调用颜色解析

## 3. Hydration Mismatch（SSR渲染不匹配）

### 错误信息
```
A tree hydrated but some attributes of the server rendered HTML didn't match the client properties.
```

### 具体差异
```
<h1 data-trae-ref="e36">  ->  <h1>登录</h1>
<label data-trae-ref="e37">  ->  <label class="form-label">
<input data-trae-ref="e27">  ->  <input type="text" ...>
<input data-trae-ref="e28">  ->  <input type="password" ...>
<input data-trae-ref="e29">  ->  <input type="text" ...>
<button data-trae-ref="e30">  ->  <button type="submit" ...>登录</button>
```

### 原因分析
- SSR渲染的HTML包含 `data-trae-ref` 属性，但客户端渲染时这些属性被移除或不存在
- 这可能是TRAE IDE的调试工具在SSR阶段注入的属性

### 影响范围
- React会记录警告，但通常不影响功能
- 可能导致轻微的闪烁或性能问题

### 处理建议
1. 检查是否有TRAE IDE的代码注入
2. 如果是第三方工具导致，考虑在生产环境禁用
3. 确保服务端和客户端渲染逻辑一致

## 5. Scroll Behavior警告

### 错误信息
```
Detected `scroll-behavior: smooth` on the `<html>` element.
To disable smooth scrolling during route transitions, add `data-scroll-behavior="smooth"` to your <html> element.
```

### 原因分析
Next.js检测到全局设置了 `scroll-behavior: smooth`，建议添加 `data-scroll-behavior="smooth"` 属性以避免路由切换时的滚动冲突。

### 影响范围
- 路由切换时可能出现滚动位置不一致

### 处理建议
在HTML模板中添加 `data-scroll-behavior="smooth"` 属性。

## 6. Fast Refresh警告（开发环境）

### 错误信息
```
[Fast Refresh] performing full reload
Fast Refresh will perform a full reload when you edit a file that's imported by modules outside of the React rendering tree.
```

### 原因分析
编辑了被React渲染树之外的模块导入的文件，导致Fast Refresh无法热更新，需要全量刷新。

### 处理建议
**忽略** - 开发环境下的正常现象。如需优化，可将非React组件导出移到单独文件中。

## 7. webkitdirectory属性警告（已修复）

### 错误信息
```
Received `true` for a non-boolean attribute `webkitdirectory`.
If you want to write it to the DOM, pass a string instead: webkitdirectory="true" or webkitdirectory={value.toString()}.
```

### 原因分析
在React组件中，`webkitdirectory` 属性被设置为布尔值 `true`，但HTML属性需要字符串值。

### 修复方案
将 `webkitdirectory={true}` 改为 `webkitdirectory="true"`。

- `web/app/admin/themes/page.tsx`（第216行）
