## 3. 低优先级 / 代码质量建议

### 3.1 SQL 内联在 API 层

`admin.go` 和 `site.go` 中大量直接写 SQL 查询（通知、用户、子站点链接），没有像 `content/articles.go` 那样抽取到业务逻辑层。

**建议：** 将查询逻辑迁移到 `internal/content/` 包中，保持 API 层只做参数绑定和响应序列化。例如：
- `internal/content/notifications.go`
- `internal/content/subsite_links.go`
- `internal/content/files.go`
