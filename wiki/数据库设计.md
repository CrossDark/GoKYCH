# 数据库设计

数据库使用 MySQL 8.0，字符集 `utf8mb4`，排序规则 `utf8mb4_unicode_ci`。所有表在应用启动时自动创建（`CREATE TABLE IF NOT EXISTS`）；新增字段通过 migration 逐步添加。

## 表总览

| # | 表名 | 说明 |
|---|------|------|
| 1 | `users` | 用户 |
| 2 | `articles` | 文章（统一 5 种类型） |
| 3 | `tags` | 标签 |
| 4 | `article_tags` | 文章-标签关联 |
| 5 | `comments` | 评论（含行评论） |
| 6 | `ratings` | 评分 |
| 7 | `webauthn_credentials` | WebAuthn 凭证（Passkey） |
| 8 | `subsite_links` | 子站链接 |
| 9 | `featured_articles` | 精选文章 |
| 10 | `notifications` | 通知 |
| 11 | `static_files` | 静态文件 |
| 12 | `typst_files` | Typst 源文件 |
| 13 | `typst_cache` | Typst 编译缓存 |
| 14 | `api_keys` | API 密钥 |
| 15 | `typst_compile_queue` | Typst 编译队列 |
| 16 | `article_deps` | 文章跨依赖关系 |

---

## 表结构详情

### 1. users — 用户表

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | INT AUTO_INCREMENT | 主键 |
| `username` | VARCHAR(64) UNIQUE | 用户名 |
| `password_hash` | VARCHAR(255) | bcrypt 密码哈希 |
| `nickname` | VARCHAR(128) | 昵称 |
| `role` | ENUM('user','admin','owner') | 角色，默认 `user` |
| `avatar` | VARCHAR(255) | 头像路径 |
| `bio` | VARCHAR(500) | 个人简介 |
| `social_email` | VARCHAR(255) | 社交邮箱（migration 添加） |
| `social_github` | VARCHAR(255) | GitHub 链接（migration 添加） |
| `social_qq` | VARCHAR(255) | QQ 链接（migration 添加） |
| `created_at` | DATETIME | 创建时间 |

### 2. articles — 文章表

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | INT AUTO_INCREMENT | 主键 |
| `type` | ENUM('md','wikidot','html','bbcode','typst') | 文章类型 |
| `slug` | VARCHAR(255) | URL 友好标识 |
| `title` | VARCHAR(255) | 标题 |
| `content` | LONGTEXT | 正文内容 |
| `rendered_html` | MEDIUMTEXT | 预渲染 HTML 缓存（migration 添加） |
| `author_id` | INT | 作者 ID（外键可为空） |
| `created_at` | DATETIME | 创建时间 |
| `updated_at` | DATETIME | 更新时间（自动维护） |

- 唯一约束：`(type, slug)`
- 全文索引：`ft_title_content (title, content)` 用于搜索

### 3. tags — 标签表

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | INT AUTO_INCREMENT | 主键 |
| `name` | VARCHAR(64) UNIQUE | 标签名 |

### 4. article_tags — 文章标签关联

| 字段 | 类型 | 说明 |
|------|------|------|
| `article_id` | INT | 文章 ID（外键 → articles） |
| `tag_id` | INT | 标签 ID（外键 → tags） |

- 联合主键：`(article_id, tag_id)`
- 级联删除

### 5. comments — 评论表

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | INT AUTO_INCREMENT | 主键 |
| `article_id` | INT | 文章 ID（外键 → articles） |
| `line_number` | INT | 行号，NULL 为全文评论 |
| `user_id` | INT | 评论者 ID（migration 添加） |
| `author_name` | VARCHAR(128) | 显示名称，默认"匿名" |
| `content` | VARCHAR(500) | 评论内容 |
| `created_at` | DATETIME | 创建时间 |

- `line_number` 区分全文评论与行评论
- 级联删除（随文章删除）

### 6. ratings — 评分表

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | INT AUTO_INCREMENT | 主键 |
| `article_id` | INT | 文章 ID（外键 → articles） |
| `user_id` | INT | 评分者 ID |
| `author_name` | VARCHAR(128) | 显示名称 |
| `voter_key` | VARCHAR(141) | 投票者唯一标识 |
| `score` | DECIMAL(4,2) | 分数（-1.00 ~ 1.00） |
| `created_at` | DATETIME | 创建时间 |
| `updated_at` | DATETIME | 更新时间 |

- 唯一约束：`(article_id, voter_key)` — 每人每篇只能评一次
- 级联删除

### 7. webauthn_credentials — WebAuthn 凭证（Passkey）

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | INT AUTO_INCREMENT | 主键 |
| `user_id` | INT | 用户 ID（外键 → users） |
| `name` | VARCHAR(128) | Passkey 名称 |
| `credential_id` | VARBINARY(1024) | 凭证 ID |
| `public_key` | BLOB | 公钥 |
| `sign_count` | BIGINT | 签名计数 |
| `transports` | VARCHAR(255) | 传输方式 |
| `backup_eligible` | TINYINT(1) | 是否支持备份 |
| `created_at` | DATETIME | 创建时间 |

### 8. subsite_links — 子站链接

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | INT AUTO_INCREMENT | 主键 |
| `name` | VARCHAR(255) | 名称 |
| `url` | VARCHAR(1024) | 链接地址 |
| `description` | VARCHAR(512) | 描述 |
| `sort_order` | INT | 排序权重 |

### 9. featured_articles — 精选文章

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | INT AUTO_INCREMENT | 主键 |
| `article_id` | INT | 文章 ID（外键 → articles） |
| `sort_order` | INT | 排序权重 |

### 10. notifications — 通知

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | INT AUTO_INCREMENT | 主键 |
| `title` | VARCHAR(255) | 标题 |
| `content` | TEXT | 内容 |
| `is_important` | TINYINT(1) | 是否重要 |
| `is_active` | TINYINT(1) | 是否启用 |
| `created_at` | DATETIME | 创建时间 |
| `updated_at` | DATETIME | 更新时间 |

### 11. static_files — 静态文件

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | INT AUTO_INCREMENT | 主键 |
| `filename` | VARCHAR(255) UNIQUE | 存储文件名 |
| `original_name` | VARCHAR(255) | 原始文件名 |
| `file_path` | VARCHAR(512) | 存储路径 |
| `file_size` | BIGINT | 文件大小（字节） |
| `mime_type` | VARCHAR(128) | MIME 类型 |
| `uploaded_by` | INT | 上传者 ID |
| `created_at` | DATETIME | 上传时间 |

### 12. typst_files — Typst 源文件

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | INT AUTO_INCREMENT | 主键 |
| `article_id` | INT | 文章 ID（外键 → articles） |
| `filename` | VARCHAR(255) | 文件名 |
| `content` | LONGTEXT | Typst 源码 |

- 唯一约束：`(article_id, filename)`

### 13. typst_cache — Typst 编译缓存

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | INT AUTO_INCREMENT | 主键 |
| `article_id` | INT UNIQUE | 文章 ID（外键 → articles） |
| `html_content` | LONGTEXT | 编译后的 HTML |
| `pdf_content` | LONGBLOB | 编译后的 PDF |
| `dependencies` | TEXT | 依赖文件列表 |
| `compiled_at` | DATETIME | 编译时间 |

### 14. api_keys — API 密钥

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | INT AUTO_INCREMENT | 主键 |
| `user_id` | INT | 用户 ID（外键 → users） |
| `key_hash` | VARCHAR(64) UNIQUE | API 密钥哈希 |
| `name` | VARCHAR(128) | 密钥名称 |
| `last_used_at` | DATETIME NULL | 最后使用时间 |
| `created_at` | DATETIME | 创建时间 |

- 级联删除（随用户删除）

### 15. typst_compile_queue — Typst 编译队列

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | INT AUTO_INCREMENT | 主键 |
| `article_id` | INT | 文章 ID（外键 → articles） |
| `status` | ENUM('pending','compiling','done','failed') | 编译状态 |
| `priority` | INT | 优先级（数值越大越优先） |
| `created_at` | DATETIME | 创建时间 |
| `updated_at` | DATETIME | 更新时间 |

- 索引：`idx_status_priority (status, priority DESC)` 用于调度

### 16. article_deps — 文章跨依赖关系

| 字段 | 类型 | 说明 |
|------|------|------|
| `article_id` | INT | 文章 ID（外键 → articles） |
| `depends_on_id` | INT | 被依赖文章 ID（外键 → articles） |

- 联合主键：`(article_id, depends_on_id)`
- 记录 Typst 文章之间的 `#import` 依赖关系
- 级联删除

---

## 关系图

```
users
  ├── articles (author_id)
  │     ├── article_tags → tags
  │     ├── comments (user_id)
  │     ├── ratings (user_id)
  │     ├── featured_articles
  │     ├── typst_files
  │     ├── typst_cache
  │     ├── typst_compile_queue
  │     └── article_deps (自引用)
  ├── webauthn_credentials
  ├── api_keys
  └── static_files (uploaded_by)

notifications (独立)
subsite_links (独立)
```
