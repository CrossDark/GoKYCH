# 开发指南

## 环境要求

| 工具 | 版本 | 说明 |
|------|------|------|
| Go | 1.26+ | 后端编译 |
| Node.js | 18+ | 前端构建 |
| MySQL | 8.0+ | 数据库（或使用 Docker） |
| Docker | 20.10+ | 可选，用于容器化开发 |

## 本地开发环境搭建

### 方式一：Docker MySQL + 本地后端

**1. 启动 MySQL**

```bash
docker compose up -d mysql
```

MySQL 运行在 `localhost:3307`（映射到容器内 3306）。

**2. 配置环境变量**

```bash
cp .env.example .env
```

修改 `.env` 中的数据库端口：

```
DB_PORT=3307
```

**3. 启动后端**

```bash
go run ./cmd/gokych
```

后端运行在 `http://localhost:8000`，首次启动会自动建表和创建默认管理员。

**4. 启动前端**

```bash
cd web
npm install
npm run dev
```

前端运行在 `http://localhost:3000`，支持热重载。

### 方式二：全 Docker

```bash
docker compose up -d
cd web && npm install && npm run dev
```

## 项目结构说明

### 后端模块划分

```
internal/
├── api/          # HTTP 层：路由、处理器、中间件
├── auth/         # 认证层：密码、会话、速率限制
├── config/       # 配置加载
├── content/      # 业务逻辑层：文章、评论、评分、标签
│   └── parsers/  # 标记语言解析器
├── core/         # 基础设施层：数据库、Schema、设置
└── typst/        # Typst 排版集成
```

### 添加新 API 的步骤

1. 在 `internal/api/` 下创建或修改处理器文件
2. 在 `internal/api/router.go` 的 `Setup()` 方法中注册路由
3. 如需新的业务逻辑，在 `internal/content/` 下添加
4. 如需新的数据库表，在 `internal/core/schema/schema.go` 的 `allTables` 中添加 DDL

### 添加新文章类型

1. 在 `internal/content/parsers/` 下创建新的解析器
2. 在 `internal/content/articles.go` 中注册类型到渲染流程
3. 在 `web/app/` 下创建对应的前端页面目录
4. 更新数据库 `articles` 表的 `type` ENUM

## 开发规范

### 后端

- **包命名**：使用小写短名称，如 `auth`、`config`、`content`
- **错误处理**：显式处理所有错误，使用 `log.Printf` 记录非致命错误
- **SQL 查询**：使用参数化查询（`?` 占位符），防止 SQL 注入
- **中间件顺序**：安全头 → 请求 ID → 会话 → 用户加载 → CSRF → 权限

### 前端

- **组件命名**：PascalCase，如 `ArticleCard.tsx`
- **页面路由**：使用 Next.js App Router 文件约定
- **类型定义**：在 `web/lib/types.ts` 中集中定义
- **API 调用**：通过 `web/lib/api.ts` 统一封装

### Git 提交规范

建议遵循 Conventional Commits：

```
feat: 添加文章搜索功能
fix: 修复评论分页错误
docs: 更新 API 文档
refactor: 重构配置加载逻辑
chore: 升级依赖版本
```

## 调试技巧

### 后端调试

设置 `GIN_MODE=debug` 启用 Gin 调试模式，会输出更详细的错误信息。

```bash
GIN_MODE=debug go run ./cmd/gokych
```

查看 SQL 日志：在 `internal/core/db/db.go` 中可临时开启 SQL 日志输出。

### 前端调试

```bash
cd web
npm run dev  # 支持热重载和 React DevTools
```

### 数据库调试

Docker MySQL 端口映射为 `3307`，可用本地客户端连接：

```bash
mysql -h 127.0.0.1 -P 3307 -u gokych -pgokych gokych
```

## 常见问题

### Q: 启动时报 "failed to connect database"

检查 MySQL 是否已启动。Docker 方式需等待健康检查通过：

```bash
docker compose ps
```

### Q: 前端 API 调用 404

确认后端运行在 `8000` 端口，前端 `web/lib/api.ts` 中的 API 地址配置正确。

### Q: 登录失败 "rate limit exceeded"

默认有登录速率限制，等待一段时间后重试，或重启后端重置限制。

### Q: 如何重置管理员密码

直接更新数据库：

```sql
-- 生成 bcrypt 哈希（需借助 Go 或其他工具）
UPDATE users SET password_hash = '<new-bcrypt-hash>' WHERE username = 'admin';
```
