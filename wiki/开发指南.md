# 开发指南

## 开发环境要求

| 工具 | 版本 | 说明 |
|------|------|------|
| Go | 1.26+ | 后端编译与运行 |
| Node.js | 20+ | 前端构建与开发服务器 |
| MySQL | 8.0+ | 数据库 |
| typst CLI | - | 可选，用于 Typst 文章编译（不安装则 Typst 文章显示编译中占位符） |

相关文档：[[配置说明]]、[[部署指南]]

## 本地开发步骤

参考 [[README]] 的本地开发部分：

```bash
# 1. 准备 MySQL 8.0+ 与一个空库
mysql -u root -p -e "CREATE DATABASE gokych DEFAULT CHARSET utf8mb4;"

# 2. 复制环境模板
cp .env.example .env   # 修改 DB_USER / DB_PASSWORD / ADMIN_PASSWORD

# 3. 启动后端（自动建表 + seed 默认 owner）
go run ./cmd/gokych

# 4. 启动前端（另一终端）
cd web
npm install
npm run dev
# 打开 http://localhost:3000
# 后台 http://localhost:3000/admin  →  admin / admin123
```

> typst CLI 安装：`brew install typst` 或从 [typst.app](https://typst.app) 下载。

## 常用命令

### Go 后端

| 命令 | 说明 |
|------|------|
| `go run ./cmd/gokych` | 启动开发服务器（自动建表+seed） |
| `go build ./...` | 编译所有包 |
| `go test ./...` | 运行所有测试 |
| `go vet ./...` | 静态代码检查 |

### Web 前端

所有命令在 `web/` 目录下执行：

| 命令 | 说明 |
|------|------|
| `npm run dev` | 启动开发服务器（热重载） |
| `npm run build` | 构建生产版本 |
| `npm run typecheck` | TypeScript 类型检查 |
| `npm run lint` | ESLint 代码检查 |
| `npm run cf:build` | Cloudflare Workers 构建 |
| `npm run cf:deploy` | 部署到 Cloudflare Workers |
| `npm run cf:preview` | 预览 Cloudflare 部署 |

## 开发注意事项

### 代码风格

- **注释规范**：关键逻辑、非显而易见的设计决策、安全相关的代码应附注释；避免对自解释代码加冗余注释
- **Go**：使用 `gofmt` 格式化，遵循标准 Go 项目布局（`internal/` 私有，`cmd/` 入口）
- **TypeScript/React**：使用函数组件 + hooks，类型定义集中在 `web/lib/types.ts`

### 权限系统

- 三级角色体系：
  - **owner（站长）**：最高权限，可管理用户/角色/站点设置/更新
  - **admin（管理员）**：可编辑/删除所有文章、管理通知/标签/文件/首页
  - **user（普通用户）**：可创建文章；默认仅能编辑/删除自己的文章
- `canModifyArticle` 是 Server 方法，通过读取 settings 中的 `allow_all_edit` 开关判断权限

### 前端 API 调用

- 统一通过 `web/lib/api/client.ts` 的 `request()` 函数发起 API 请求
- 不要直接使用 fetch 或其他 HTTP 客户端

### 中间件顺序

- CORS 中间件必须在 CSRF 中间件之前安装
- CORS preflight 请求（OPTIONS）直接返回 204，不经过后续中间件

### Typst 编译

- Typst 编译采用异步 worker 模式，不阻塞请求
- 支持跨文章依赖（`#import "@slug"` / `#include "@slug"`），修改一篇文章会触发依赖级联重编译
