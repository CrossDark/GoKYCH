# 部署指南

## Docker Compose 部署（推荐）

### 前提条件

- Docker Engine 20.10+
- Docker Compose v2+

### 步骤

**1. 准备环境变量**

```bash
cp .env.example .env
# 编辑 .env，修改 SESSION_SECRET 和数据库密码
```

**2. 启动服务**

```bash
docker compose up -d
```

这会启动两个服务：
- **mysql** — MySQL 8.0 数据库，端口映射 `3307:3306`
- **backend** — GoKYCH 后端，端口映射 `8000:8000`

MySQL 健康检查通过后，后端才会启动。

**3. 验证**

```bash
curl http://localhost:8000/api/health
# 预期响应：{"status":"ok"}
```

**4. 启动前端**

```bash
cd web
npm install
npm run build
npm run start
```

前端默认运行在 `http://localhost:3000`。

### 数据持久化

Docker Compose 定义了两个持久化卷：

| 卷名 | 用途 |
|------|------|
| `mysql_data` | MySQL 数据文件 |
| `app_data` | 应用数据（设置、头像、插件、主题、Typst 文件） |

### 常用命令

```bash
# 查看日志
docker compose logs -f backend

# 重启服务
docker compose restart backend

# 停止所有服务
docker compose down

# 停止并删除数据（危险！）
docker compose down -v
```

## 手动部署

### 前提条件

- Go 1.26+
- MySQL 8.0+
- Node.js 18+（前端构建）

### 后端

**1. 编译**

```bash
CGO_ENABLED=0 go build -o gokych ./cmd/gokych
```

**2. 准备配置**

```bash
cp .env.example .env
# 编辑 .env 配置数据库连接等
```

**3. 确保 MySQL 已启动**

```bash
mysql -u root -p -e "CREATE DATABASE gokych CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"
mysql -u root -p -e "CREATE USER 'gokych'@'localhost' IDENTIFIED BY 'gokych';"
mysql -u root -p -e "GRANT ALL ON gokych.* TO 'gokych'@'localhost';"
```

**4. 启动**

```bash
./gokych
```

应用会自动创建表结构和默认管理员。

### 前端

```bash
cd web
npm install
npm run build
npm run start
```

## Docker 单独构建镜像

```bash
# 构建镜像
docker build -t gokych .

# 运行（需外部 MySQL）
docker run -d \
  -p 8000:8000 \
  -e DB_HOST=your-mysql-host \
  -e DB_PORT=3306 \
  -e DB_USER=gokych \
  -e DB_PASSWORD=gokych \
  -e DB_NAME=gokych \
  -v gokych_data:/app/data \
  gokych
```

## 反向代理配置

### Nginx 示例

```nginx
server {
    listen 80;
    server_name your-domain.com;

    location / {
        proxy_pass http://127.0.0.1:3000;  # 前端
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }

    location /api/ {
        proxy_pass http://127.0.0.1:8000;  # 后端 API
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

使用反向代理时，需在 `.env` 中配置：

```
TRUSTED_PROXIES=127.0.0.1
```

以确保后端能正确获取客户端真实 IP。
