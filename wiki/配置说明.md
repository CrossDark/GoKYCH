# 配置说明

GoKYCH 的配置采用**三级优先级**机制，高优先级覆盖低优先级：

```
环境变量 > YAML 配置文件 > 默认值
```

## 环境变量（.env 文件）

在项目根目录创建 `.env` 文件，参考 `.env.example`：

```bash
cp .env.example .env
```

### 数据库配置

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `DB_HOST` | `localhost` | MySQL 主机地址 |
| `DB_PORT` | `3306` | MySQL 端口 |
| `DB_USER` | `gokych` | 数据库用户名 |
| `DB_PASSWORD` | `gokych` | 数据库密码 |
| `DB_NAME` | `gokych` | 数据库名称 |
| `DB_CHARSET` | `utf8mb4` | 字符集 |
| `DB_POOL_MIN` | `2` | 连接池最小连接数 |
| `DB_POOL_MAX` | `10` | 连接池最大连接数 |
| `DB_POOL_RECYCLE` | `3600` | 连接回收时间（秒） |

### 应用配置

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `APP_PORT` | `8000` | HTTP 服务端口 |
| `GIN_MODE` | `debug` | Gin 运行模式：`debug` / `release` / `test` |
| `SESSION_SECRET` | `change-me-to-a-random-string` | 会话加密密钥（**生产环境务必修改**） |
| `ADMIN_USERNAME` | `admin` | 默认管理员用户名 |
| `ADMIN_PASSWORD` | `admin123` | 默认管理员密码（仅首次初始化时生效） |
| `DATA_DIR` | `data` | 数据目录路径 |
| `TRUSTED_PROXIES` | _(空)_ | 可信代理 IP/CIDR，逗号分隔。空值表示不信任任何代理，仅使用 RemoteAddr |

## YAML 配置文件

数据库配置也可通过 YAML 文件指定，路径为 `data/settings/db.yaml`：

```yaml
mysql:
  host: localhost
  port: 3306
  user: gokych
  password: gokych
  database: gokych
  charset: utf8mb4
  pool:
    minsize: 2
    maxsize: 10
    pool_recycle: 3600
```

配置模板位于 `configs/db.yaml.example`。

## 站点设置

站点级别的设置存储在 `data/settings/settings.yml`，由应用自动创建和维护，可通过管理后台 API 修改：

```
GET /api/admin/settings   — 查看
PUT /api/admin/settings   — 修改（需 owner 角色）
```

## 数据目录结构

`DATA_DIR`（默认 `data`）下包含以下子目录，应用启动时自动创建：

```
data/
├── settings/    # 配置文件（db.yaml, settings.yml）
├── avatars/     # 用户头像上传
├── plugins/     # 插件目录
├── themes/      # 主题文件
└── typst/       # Typst 编译临时文件
```

## 配置优先级示例

假设 `db.yaml` 中 `host: yaml-host`，`.env` 中 `DB_HOST=env-host`，则最终使用 `env-host`。

如果只设置了 `db.yaml` 的 `host`，环境变量未设置，则使用 `yaml-host`。

如果两者都未设置，则使用默认值 `localhost`。

## 生产环境建议

1. **修改 `SESSION_SECRET`** 为随机长字符串
2. **修改默认管理员密码** 或首次登录后立即修改
3. **设置 `GIN_MODE=release`** 关闭调试模式
4. **配置 `TRUSTED_PROXIES`** 如使用反向代理
5. **使用强数据库密码** 并限制数据库访问来源
